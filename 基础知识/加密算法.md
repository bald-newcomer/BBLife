当前主流的加密算法有三种类型

# 加密算法分类

## 对称加密 (Symmetric Encryption)
特点：加密和解密使用相同的密钥，速度快、效率高。常用于批量数据加密、数据库加密、文件加密。

缺点：密钥分发困难。

常见算法类型：AES、SM4。

## 非对称加密 (Asymmetric Encryption)
特点：使用公钥加密、私钥解密（或反之），解决密钥分发问题。常用于SSL/TLS、数字签名、密钥交换

缺点：速度慢、计算资源消耗大。

常见算法类型：RSA、ECC、SM2。

## 哈希函数 (Hash Functions)
特点：单向不可逆、固定长度输出，常用于数据完整性验证、密码存储、数字签名

常见算法类型：SHA-256、SHA-3、SM3

# 常用加密算法

## AES
```java
   /**
     * AES-GCM加解密数据
     * domainId
     *
     * @param data     待加密或解密的数据
     * @param plainKey 明文密钥（十六进制字符串）
     * @return 加密或解密后的数据
    */
    public static String gcmDecrypt(String data, String plainKey) {
        try {
            List<String> split = StrUtil.split(data, SPLIT_STR);
            if (split.size() != 2) {
                LOGGER.error("incorrect aes format: {}", data);
                return data;
            }
            byte[] src = Base64.decode(split.get(0));
            byte[] value = Base64.decode(split.get(1));
            SecretKey secretKey = new SecretKeySpec(HexUtil.decodeHex(plainKey), AES_ALGORITHM_NAME);
            GCMParameterSpec gcmParameterSpec = new GCMParameterSpec(GCM_TAG_LENGTH, src);

            Cipher cipher = Cipher.getInstance(AES_TRANSFORMATION);
            cipher.init(Cipher.DECRYPT_MODE, secretKey, gcmParameterSpec);
            cipher.updateAAD(AAD_SALT_DATA.getBytes());
            byte[] result = cipher.doFinal(value);
            return StrUtil.str(result, CharsetUtil.CHARSET_UTF_8);
        } catch (IllegalBlockSizeException | BadPaddingException | InvalidAlgorithmParameterException |
                 NoSuchPaddingException | NoSuchAlgorithmException | InvalidKeyException e) {
            LOGGER.error("aes decrypt error: " + data, e);
            return data;
        }
    }

    /**
     * AES-GCM加解密数据
     *
     * @param data     待加密或解密的数据
     * @param plainKey 明文密钥（十六进制字符串）
     * @return 加密或解密后的数据
     */
    public static String gcmEncrypt(String data, String plainKey) {
        try {
            byte[] src = generateIVSource();
            SecretKey secretKey = new SecretKeySpec(HexUtil.decodeHex(plainKey), AES_ALGORITHM_NAME);
            GCMParameterSpec gcmParameterSpec = new GCMParameterSpec(GCM_TAG_LENGTH, src);

            Cipher cipher = Cipher.getInstance(AES_TRANSFORMATION);
            cipher.init(Cipher.ENCRYPT_MODE, secretKey, gcmParameterSpec);
            cipher.updateAAD(AAD_SALT_DATA.getBytes());
            byte[] result = cipher.doFinal(StrUtil.bytes(data, CharsetUtil.CHARSET_UTF_8));
            return Base64.encode(src) + SPLIT_STR + Base64.encode(result);
        } catch (IllegalBlockSizeException | BadPaddingException | InvalidAlgorithmParameterException |
                 NoSuchPaddingException | NoSuchAlgorithmException | InvalidKeyException e) {
            return data;
        }
    }

    @NotNull
    private static byte[] generateIVSource() {
        byte[] src = new byte[GCM_IV_LENGTH];
        RandomUtil.getSecureRandom().nextBytes(src);
        return src;
    }
```
