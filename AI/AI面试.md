# 知识点

## Top-p和Temperature
**Top-p**: 核采样，控制着模型选择下一个词的随机性和多样性
**Temperature**: 可以形象地理解为对“概率分布”进行“平滑”或“锐化”处理

前者控制动态筛选出一个候选词集合，后者调整所有候选词的概率分布形状

### 示例：
* 代码生成：Temperature=0.2, Top-p=1.0
* 创意故事：Temperature=1.3, Top-p=0.9
* 事实问答：Temperature=0.3, Top-p=1.0
* 头脑风暴：Temperature=1.5, Top-p=1.0

## ReAct（Reason + Act，推理与行动）

### 定义
让模型在推理（Reason）和行动（Act）之间交替进行——先思考，然后采取行动（如调用工具、搜索信息），根据观察结果继续推理，直到得出答案。

Thought（思考）→ Action（行动）→ Observation（观察）→ Thought（思考）→ ... → Answer（答案）

### 示例
* 简单分类任务 → Few-shot，例：情感分类、命名实体识别

* 逻辑/数学推理 → CoT 例：数学应用题、逻辑谜题

* 需要外部信息/多步交互 → ReAct 例：网页浏览、数据查询、自动化操作、智能客服

## 如何解决LLM在Agent任务中的“幻觉”问题？有哪些工程化手段？
* 多模型协作：多模型审查辩论，多分支验证、质量门禁
* 提示词和推理优化：提示词明确审查目标和严谨程度，引入RAG和权威信息tool
* 模型优化：引入事实性标签来纠正偏好、


大模型优化：

### 架构层面的多智能体协作
1. 多智能体辩论（Multi-Agent Debate，让多个LLM Agent扮演不同角色（如回答者、批评者、裁判），通过结构化辩论来识别和修正错误。
2. 委员会模式（Council Mode），将同一个问题并行发送给多个异构模型（如GPT-4、Claude、DeepSeek各一个实例），通过专门的共识模型综合各方输出。
3. Agent先通过熵估计进行内省推理（检测到高不确定性时主动回顾视觉/上下文信息），再通过外部多模态多智能体协作进行迭代验证和修正。
4. RAG与外部知识增强
5. 分支验证（Branch Verification）
   
   原理：Agent不是失败后重试一次，而是同时提出多个修复方案，在隔离容器中并行运行，只有通过确定性测试的才被采纳。

   应用场景：代码生成——Agent写代码后，在沙盒中运行单元测试，根据真实报错来修正。

6. LLM-as-Judge质量门
    原理：用一个专门的质量评估模型（或同一个模型的高温版本）对输出进行评分，低于阈值则触发重生成或人工介入。  
### 提示工程与推理优化（成本低，易部署）
1. 验证链（Chain-of-Verification, CoVe）：直接让模型审视自己的输出，它大概率会坚持原有立场（确认偏差）。
2. 增强数据注册表（Enhanced Data Registry）：将外部权威数据源结构化注册，提示词中明确告诉模型“当遇到X类型问题时，必须查阅数据注册表中的Y条目”。
3. 领域术语表注入：在提示词中注入任务相关的标准化术语及其定义，强制模型使用规范表述。
### 模型层的激活干预（无需重训练，实时生效）
自适应激活消除（AAC）：在推理阶段识别与幻觉相关的神经元节点（H-Nodes），通过置信度加权的前向钩子实时抑制这些激活。
### 训练与对齐层面的优化（根本性解决，成本高）
事实感知偏好学习（F-DPO）：扩展Direct Preference Optimization（DPO），引入事实性标签来纠正偏好排序——确保“被选中的回答”在事实性上不低于“被拒绝的回答”。

## MCP
### 定义
基础协议：MCP所有通信都基于 JSON-RPC 2.0 消息格式，包含消息类型：请求、响应、通知
生命周期：初始化、就绪、关闭
安全原则：用户同意与控制、数据隐私、工具安全、采样控制

#### 核心功能
Tool、Resource、Promot
#### Resource
表示服务器向客户端提供的各类数据，包括文件内容、数据库记录、API响应、实时系统数据、图片等。每个资源由唯一的URI标识。

#### Promot
预定义的模板化消息和工作流，可以接受动态参数，指导用户完成特定操作。例如斜杠命令、菜单选项等。

主要作用是模板化的提示词，用户只需要提供简单关键词，LLM就能得到预制完整的提示词

#### Tool
可供AI模型调用的可执行函数，从简单的计算到复杂的API交互。AI模型通过tools/list发现可用工具，通过tools/call调用工具执行操作。

此外，客户端也可向服务器提供采样（服务器发起的LLM交互）、根目录（文件系统边界查询）等高级功能。
